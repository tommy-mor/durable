Notes

  • List/Deque/Map/Nested/Record reads and writes go through the same key codec on every backend; only the storage engine differs.
  • SyncWal single commits pay the fsync floor; batched DisableWal commits amortize it.
  • map_clear is a range tombstone on rocksdb, key expansion on redb/sled — watch the shapes diverge.
  • rocksdb: rocksdb 0.25.0 (RocksDB 11.8.1).
  • redb: redb 4.4.0.
  • sled: sled 0.34.7.
  • memory: std Vec/VecDeque/BTreeMap.
